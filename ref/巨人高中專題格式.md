# 巨人高中專題實作報告｜格式規格

> 來源檔：`巨人高中專題格式.docx`（115 學年度範例＋註解格式說明）  
> 整理原則：以文件**註解／內文明文**與**使用者確認**為準；樣式或範例實測僅作佐證。不捏造。  
> 機器可讀：[`巨人高中專題格式.rules.json`](./巨人高中專題格式.rules.json)（可依 `section` / `applies_to` / `full_document_only` 篩選）

---

## 格式重點摘要

| 項目 | 規定 |
|------|------|
| 紙張 | A4（21.0 × 29.7 cm），直式 |
| 邊界（全節） | 上下 **2.54 cm**、左右 **3.17 cm**；**無 gutter**（使用者確認 2026-10-31） |
| 中文字型 | **標楷體** |
| 英文／數字 | **Times New Roman** |
| 內文 | 12 級、**左右對齊（justify）**、首行縮排 2 字元、**1.5 倍行高**、段間不空行 |
| 章標題 | 「第○章 …」、16 級粗體、置中、**2 倍行高** |
| 節標題 | 「1-1 …」、14 級粗體、靠左不縮排、1.5 倍行高 |
| 層次編碼 | 第○章 → 1-1 → 一、→（一）→ 1. →（1） |
| 正文結構 | **強制四章**：緒論、文獻探討、專題成果、結論（R110–R115） |
| 字數／頁數 | 字數**無限制**；頁數**整份文件（含封面、目錄、附錄）總頁數 ≥10**（R109；使用者確認 2026-10-31） |
| 測試方式 | 可依章測試；`full_document_only` 規則僅整份文件檢查 |

---

## 依出現位置分組（供逐章測試）

學生完成一章即可先測該章：取該章 `rule_ids`，並套用下列「測該章時要套用的全文類規則」；**略過**標了 `full_document_only` 的規則（目錄、整份頁數、強制四章總檢、封面／摘要等）。

| 組 | section | 本章／本節專屬規則數 | 測該章時另套用之全文類規則數 |
|----|---------|----------------------|------------------------------|
| 全文類 | `global` | 62 | — |
| 第一章（緒論） | `ch1` | 2 | 31 |
| 第二章（文獻探討） | `ch2` | 1 | 31 |
| 第三章（專題成果） | `ch3` | 1 | 31 |
| 第四章（結論） | `ch4` | 2 | 31 |
| 參考文獻 | `references` | 9 | 6 |

規則總數：**77**（含全文類 home 62；`full_document_only` 30 條）

## 內文層次編碼（文件原文）

```
第○章 （16 級、粗體、置中）
1-1靠左對齊（14 級、粗體）
  一、縮排 1.5 字元（以下階層皆 12 級）
    (一) 縮排 2.5 字元
      1. 縮排 3 字元
        （1）縮排 4 字元
```

## 文件結構順序（範例）

1. 封面內頁 → 2. 簽名頁 → 3. 摘要＋關鍵詞 → 4. 目錄 → 5. 圖目錄 → 6. 表目錄 → 7. 第一章～第四章 → 8. 參考文獻 → 9. 附錄

## 來源與限制說明

1. **主要規格來源**為 Word 註解（author: niou / user）與 **使用者確認 2026-10-31**。  
2. 範例論文僅作章名／節名與排版佐證；與確認衝突時以確認為準。  
3. R109：字數不限；**整份文件（含封面、目錄、附錄）總頁數 ≥10**（已確認）。  
4. R112 章內節名來自範例，註解未強制，狀態為 `sample_example`。  
5. 抽出之範例圖見 `images/`。
