# 巨人高中專題實作報告｜格式規格

> 來源檔：`巨人高中專題格式.docx`（115 學年度範例＋註解格式說明）  
> 整理原則：以文件**註解／內文明文**為準；樣式或範例實際數值僅作佐證。不一致處標「待確認」，不捏造。  
> 機器可讀規則：同目錄 [`巨人高中專題格式.rules.json`](./巨人高中專題格式.rules.json)

## 格式重點摘要

| 項目 | 規定 |
|------|------|
| 紙張 | A4（21.0 × 29.7 cm），直式 |
| 邊界（全節） | 上下 **2.54 cm**、左右 **3.17 cm**；**無 gutter**（封面／目錄／正文皆同；使用者確認 2026-10-31） |
| 中文字型 | **標楷體** |
| 英文／數字 | **Times New Roman** |
| 內文 | 12 級、左右對齊或靠左（見規則）、首行縮排 2 字元、**1.5 倍行高**、段間不空行 |
| 章標題 | 「第○章 …」、16 級粗體、置中、**2 倍行高** |
| 節標題 | 「1-1 …」、14 級粗體、靠左不縮排、1.5 倍行高 |
| 層次編碼 | 第○章 → 1-1 → 一、→（一）→ 1. →（1） |
| 直接引用 | 粗體＋引號，原文 ≤ 50 字（不含標點） |
| 正文引註 | 中：（姓名，年代）；英：(Surname, year) |
| 參考文獻 | 依中學生網站 APA；紙本至少 3 篇；中文在前、英文在後 |
| 圖 | 編號「章－號」、圖置中、圖名在**下**置中；圖 ≤ 頁面 1/4 |
| 表 | 編號「章－號」、表名在**上**靠左；表格置中 |
| 頁碼 | 前頁大寫羅馬數字；正文阿拉伯數字（樣式推導＋註解） |
| 字數／頁數上限 | **無限制**（巨人高中自訂專題格式；不套用中學生小論文頁數限制；使用者確認 2026-10-31） |

## 文件結構（範例目錄順序）

1. 封面內頁  
2. 簽名頁（口試合格證明）  
3. 摘要 + 關鍵詞（3–5 個）  
4. 目錄  
5. 圖目錄  
6. 表目錄  
7. 第一章 緒論（含 1-1 研究動機、1-2 研究目的、1-3 研究方法、1-4 研究流程）  
8. 第二章 文獻探討  
9. 第三章 專題成果  
10. 第四章 結論與建議  
11. 參考文獻  
12. 附錄（如問卷）

> 註：章名與節數可視題目調整；上列為範例實際結構。是否強制四章：**待確認**（註解僅示「第一章…第四章」寫法）。

## 來源與限制說明

1. **主要規格來源**為 Word 註解（author: niou / user），非另附獨立「格式手冊」正文。  
2. 本檔同時含一篇齲齒主題**範例論文**（部分章節標明省略）；範例排版若與註解／使用者確認衝突，以確認後規格為準，其餘衝突仍標「待確認」。邊界已於 2026-10-31 由使用者確認全節統一為上下 2.54 cm、左右 3.17 cm、無 gutter。  
3. 字數／頁數已於 2026-10-31 由使用者確認為無限制（R109）。其餘未在註解或內文出現的項目（例如是否必須四章）仍標未載明，不臆測。  
4. 抽出之範例圖片置於 `images/`（image1–4），供對照圖題／資料來源寫法，非格式圖示。
