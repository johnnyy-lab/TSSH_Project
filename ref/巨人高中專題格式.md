# 巨人高中專題實作報告｜格式規格

> 來源檔：`巨人高中專題格式.docx`（115 學年度範例＋註解格式說明）  
> 整理原則：以文件**註解／內文明文**與**使用者確認**為準；不捏造。  
> 編號：全文類 `R000–R099`、第一章 `R100–R199`、第二章 `R200–R299`、第三章 `R300–R399`、第四章 `R400–R499`、參考文獻 `R500–R599`（各組從頭連續）。每條含 `old_id`。  
> 機器可讀：[`巨人高中專題格式.rules.json`](./巨人高中專題格式.rules.json)

## 格式重點摘要

| 項目 | 規定 |
|------|------|
| 紙張 | A4（21.0 × 29.7 cm），直式 |
| 邊界（全節） | 上下 **2.54 cm**、左右 **3.17 cm**；**無 gutter**（使用者確認 2026-10-31） |
| 中文字型 | **標楷體** |
| 英文／數字 | **Times New Roman** |
| 內文 | 12 級、**左右對齊（justify）**、首行縮排 2 字元、**1.5 倍行高**、段間不空行 |
| 章／節標題 | 章 16pt 粗體置中 2 倍行高；節 `1-1` 14pt 粗體靠左 1.5 倍 |
| 正文結構 | **強制四章**（見 `R061`、`R100`–`R401`） |
| 字數／頁數 | 字數不限；整份文件（含封面、目錄、附錄）總頁數 ≥10（`R060`） |
| 測試方式 | 可依章測試；`full_document_only` 僅整份文件檢查 |
