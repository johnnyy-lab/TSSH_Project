## 繳交單位 → 套用組別（submission_profiles）

| 繳交單位 | 套用組別 | 規則選取 |
|----------|----------|----------|
| 第 N 章 | 該章組 + **全文類** | `chN.rule_ids` + `inherit_global`（**排除** `full_document_only`） |
| 參考文獻 | references + 全文類適用者 | `references` + 版面／字型等 inherit（排除 full_document_only） |
| 封面目錄 | **front_matter** + 全文類邊界／字型 | `front_matter.rule_ids` + `inherit_global`（R000–R006、R008–R010） |
| 完整文件 | 全部 | 所有 section 全部規則 |

JSON 鍵：`submission_profiles.chapter_1` … `chapter_4`、`references`、`front_matter`、`full_document`。

## 格式重點摘要

| 項目 | 規定 |
|------|------|
| 紙張／邊界 | A4；上下 2.54 cm、左右 3.17 cm、gutter=0（全節） |
| 字型 | 中文標楷體、英數 Times New Roman |
| 正文 | 12pt、左右對齊、首行縮 2 字、1.5 倍、段間不空行 |
| 章／節 | 章 16pt 粗體置中 2 倍行高；節 `N-N` 14pt 粗體靠左 1.5 倍 |
| 結構 | 強制四章；頁數整份 ≥10；字數不限 |
| 註解覆蓋 | Word 註解 **35** 則皆有對應規則（已拆成可獨立檢查項） |
