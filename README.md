# 高中專題

高中專題實作報告的格式規範與作品資料。

格式檢查網站在 `checker/`，目前版本 **0.1**（最小 MVP，本機測試已通過）。啟動方式見 `checker/README.md`。

## 資料夾

- `ref/`：高中專題格式參考文件
  - `高中專題格式.docx`：原始格式文件
  - `高中專題格式.md`：格式規範說明
  - `高中專題格式.rules.json`：可供程式檢查的格式規則（共 153 條）
- `semi_project/`：第 1～6 組專題半成品

| 組別 | 題目 |
|------|------|
| 第1組 | 青少年對肥胖的認知之探討 |
| 第2組 | 青少年對齲齒之認知與探討 |
| 第3組 | 憂鬱症探討 |
| 第4組 | 地中海型貧血症狀、成因及對人體影響之探討 |
| 第5組 | 青少年對糖尿病之認知與成因探討 |
| 第6組 | 血清性肝炎之表徵與探討 |

## 格式規則分組

| 分組 | 編號 | 條數 |
|------|------|------|
| 全文類 | R000–R099 | 73 |
| 第一章 緒論 | R100– | 2 |
| 第二章 文獻探討 | R200– | 1 |
| 第三章 專題成果 | R300– | 1 |
| 第四章 結論 | R400– | 2 |
| 參考文獻 | R500– | 17 |
| 封面目錄類 | R600–R699 | 57 |

繳交某一章時，需符合「該章＋全文類」規則；總頁數至少 10 頁、強制四章等規則只在繳交整份文件時檢查。
